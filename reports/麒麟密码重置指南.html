🔐 银河麒麟V10 SP1 密码重置指南

适用系统：Kylin V10 SP1 (Ubuntu/Debian底层) | 适用场景：忘记用户密码

⚠️ 改密码前必看！！！
① 先检查键盘 NumLock（9键数字锁）是否关闭，开着会导致密码输入错误！
② 密码必须是 英文 + 数字 组合，不能用纯数字！推荐如 Ngs@2026
以上两点踩坑最多，切记切记！！！
📋 前置准备

• 一台银河麒麟系统电脑（本例：联想开天主机）
• 接键盘，确保 NumLock 关闭
• 整个过程不需要U盘或外部工具

🚀 共同步骤：进入GRUB
1

进入GRUB启动菜单

开机后立刻反复按 Esc 键（联想开天按Esc），直到出现黑底白字的GRUB菜单。

⚠️ 如果按晚了直接进了登录界面，长按电源键关机重来。
2

选择 Advanced options

用 ↓方向键 移到第2个选项 Advanced options for Kylin V10 SP1，按 回车。

📘 方案一：recovery模式（简单，优先试）
3a

选择 recovery mode

选中带 (recovery mode) 的那行（第2个子选项），直接 回车。

4a

进入root shell

在恢复菜单中选择 root，回车，进入 # 命令行。

5a

修改密码

passwd 你的用户名 # 本例：passwd nygs

输入新密码（屏幕不显示字符，正常），回车，再输入一次确认。

看到 "passwd: password updated successfully" 就成功了。

6a

重启登录

reboot
💡 方案一最简单，优先试这个。如果密码改了但登录不对（被kysec拦截），用方案二。
📕 方案二：init=/bin/bash（方案一不生效时用）
3b

进入GRUB编辑模式

选中带 (recovery mode) 的那行，按 e 键进入编辑。

4b

修改启动参数

找到以 linux 开头的那行，移到行尾（security=kysec 后面），加上：

init=/bin/bash

改完这行应该是：

linux /vmlinuz-5.4.18-85-generic root=UUID=... ro single nomodeset \ console=tty1 security=kysec init=/bin/bash

然后按 Ctrl+X 启动。

5b

挂载文件系统 + 改密码

屏幕停在黑屏带光标，按一下 回车，出现 # 后依次输入：

mount -o remount,rw / # 挂载为读写 passwd 你的用户名 # 本例：passwd nygs

输入新密码两次，看到 "password updated successfully" 就成功了。

⚠️ init=/bin/bash 模式下文件系统默认只读，必须先 mount -o remount,rw /
6b

强制重启

此模式下 reboot 命令无效，用：

echo b > /proc/sysrq-trigger

或直接 长按电源键 强制关机，再开机。

🔑 登录注意事项
🚨 再次提醒！！！
① 登录前检查 NumLock（9键数字锁）是否关闭！开着会输错密码！
② 密码必须是 英文 + 数字，不能纯数字！
③ 登录界面可能默认中文输入法 → 按 Ctrl+空格 切英文再输密码
④ 密码输入框隐藏不显示字符 → 不要以为没输入上
❌ 常见踩坑
问题原因解决
密码改了但登录不对NumLock开着，数字键输入错位关掉NumLock再输密码
密码改了但登录不对kysec安全模块阻止了修改用方案二 init=/bin/bash
登录界面输密码没反应中文输入法未切换按 Ctrl+空格 切英文
命令报"未找到命令"拼写错误（psswd vs passwd）passwd 不是 psswd
reboot 命令报错init=/bin/bash 下 systemd 没启动echo b > /proc/sysrq-trigger
黑屏无响应显卡不兼容确保 linux 行有 nomodeset
