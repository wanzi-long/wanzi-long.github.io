wanggan-dojo · 网感与流量直觉训练器

书给框架，拆解读语感。每天拆 3 条爆款，每周一场隐数据盲测大考，XP 五维分开涨——把"网感"这种玄学变成可校准、可累积的能力。
作者：唐浩翔形态：Agent 技能（SKILL.md）+ 数据脚本 + 状态机 B站 · AI/知识/健身科普赛道游戏化：XP · 段位 · 连击

1. 系统定位

面向内容创作者的练功房：用真实爆款做教材，用盲测做校准，用游戏化状态机做坚持。核心判断：网感不是天赋，是"预测 → 对答案 → 校准"的循环次数。

2. 四种模式（触发词路由）

"开练/今日练功"      → Mode A 每日练功（3 条 × 拆解卡）
"继续练功"           → Mode A 续跑（读 pending.json 断点续传）
"大考/盲测/周考"      → Mode B 每周大考（6 条隐数据盲测）
"网感进度/我的段位"   → Mode C 查进度（只读，无副作用）
"拆解这条"+链接       → Mode D 自喂拆解（防刷分：单日入账上限 30 XP）

3. Mode A · 每日练功流程

  1. 脚本捞取 3 条赛道热门（封面/标题/时长/简介，隐去播放量）；脚本失败自动转用户自喂
  2. 用户按拆解卡五字段作答：钩子类型 / 情绪曲线 / 划走点 / 传播点 / 可偷的 pattern
  3. 按四维 rubric 打分（各 0-5）+ 点评：每条点评必须指出 ≥1 个用户漏掉的点；基于元数据的判断一律标注"推断"
  4. 结算入账：四维 XP 累加；连击 streak 逢 7 倍数 +20 XP；高分 pattern 自动收录进 pattern 库
  5. 输出战报：得分、XP、streak、距下一段位进度条；≥7 天没大考会提醒

4. Mode B · 每周大考（盲测校准）

密封纪律：用户提交全部预测之前，系统严禁读取答案文件，连 reveal 命令都不许跑——防自欺是训练有效的前提。
  • 6 条隐数据题（A-F 洗牌、UP 主匿名）：预测 top3 排名 + 每条量级（<1w / 1-10w / 10-100w / 100w+）+ 预测理由
  • 计分公式：top3 命中（≤30）+ 排序分（≤10）+ 量级准确（≤10）= 数据直觉 XP（≤50）；理由质量反哺钩子/情绪/划走点三维
  • 产出偏差复盘：系统性高估/低估哪类内容（标题党？封面朴素选题硬？时长信号？）→ 下周练功侧重点

5. 游戏化状态机

state.json
 ├─ xp: {hook, emotion, dropout, pattern, data}   ← 五维独立成长
 ├─ rank: 青铜→…（按总 XP 段位表定级）
 ├─ streak / best_streak                          ← 连击与最佳纪录
 ├─ sessions / exams / patterns_count             ← 累计场次
 └─ pending.json                                  ← 断点续跑状态
五维训练的能力
🎯 钩子识别前 3 秒留人力判断
💓 情绪洞察情绪曲线设计与共鸣点识别
✂️ 划走点预判流失节点的结构性感知
🧩 pattern 提炼从个案抽象可复用模式
📊 数据直觉播放量量级预测（大考专属，≥2 次大考才参与短板比较）

6. 评分纪律（防自欺机制）

  1. 打分只看推理质量，不猜用户爱听的；rubric 锚点固定，不膨胀
  2. 每条点评必须指出 ≥1 个漏点；全对也要给"还能再深一层"的追问
  3. 用户反驳有理 → 当场改分，并把修正依据追加到 rubric 笔记（可审计）
  4. 大考答案密封期绝不读答案、绝不暗示量级
  5. 自喂模式单日入账上限 30 XP，防刷分

7. 设计亮点

盲测校准
用"隐数据预测 vs 真实数据"量化网感，偏差可视化，告别"我觉得能火"
防自欺设计
密封答案、rubric 锚点、反驳改分留痕——训练系统的诚实性工程
状态机持久化
XP/段位/连击/断点全持久化，跨会话连续成长，agent 无记忆也能接续
降级与防刷
脚本失败转自喂、开卷检测、自喂上限——边界情况全部有预案
