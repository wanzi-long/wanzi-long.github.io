面试作战系统（interview-prep）

给一家公司 + 一个岗位，30-40 分钟全自动产出全套面试作战包；给面试录音，出复盘并把经验回写档案——每面一场，档案厚一层。
作者：唐浩翔GitHub：wanzi-long/interview-prep（开源） 形态：Claude Code / SKILL.md 格式 Agent 技能经真实面试全流程实战验证

1. 系统定位

源于 2026-08 真实面试全流程实战验证。把求职准备从"人肉熬夜查公司、想问题"变成"喂给 Agent 公司名 + 岗位名，自动产出全套弹药"。
面试前
公司+岗位 → 公司调研 / 财务分析 / 行业调研 PDF / 岗位分析 / S·A·B·C 四级定制题库 / 岗位特化简历 / 作战手册 / Gemini 模拟面试脚本
面试后
录音 ASR 转写 → 逐题拆解失分点 → 新考题 / 新故事回写档案与总题库（RAG 式成长）
零冷启动
无档案用户由 Agent 引导建档：旧简历自动解析，或回答 6-8 个问题成档，缺口用【待补】占位先开跑

2. 设计铁律

  1. 真实红线：话术、简历、报告中的所有经历/数字/成果必须来自个人档案，禁止编造——档案三要素（量化战绩 / STAR 故事 / 软肋清单）是系统"不虚构"的根基
  2. 成本红线：语音转写只走免费额度通道，调用前先查额度；付费资源一律禁区
  3. 用户硬约束可配置：按个人情况内置约束（示例：口语弱 → 只接异步文字类机会，不设计口语环节）
  4. 隐私红线：录音 / 简历 / 档案只本地处理，不外发

3. 启动自检与降级链

5 秒自检，缺则自动降级、不中断主流程：

工具作用降级方案
企查查 CLI国内企业全方位审查（工商/股东/司法风险 35 项）→ 博查 API
博查 API国内公司检索兜底→ Tavily / Brave
Brave API外企信息辅助→ Tavily
豆包语音HR 通话 / 面试录音 ASR→ 无录音环节时跳过
Chrome简历 / 报告 PDF 渲染→ 只出 HTML

4. 四阶段流水线

阶段产出
① 情报采集上市判定分流：上市→年报/行情/研报（营收、毛利率、逐年同比）；未上市→工商+司法风险全扫。官网抓取（GBK 站点先转码）、HR 录音 ASR
② 分析合成JD 拆解 / 薪资结构 / 考核逻辑 / 面试官画像；弹药自检（先读档案，缺要素先问用户补齐）；S/A/B/C 四级题库，每题 = 考察本质 + 深度拆解 + 定制话术 + 补丁
③ 武器与演练岗位特化简历（HTML 渲染源 → PDF，交付仅 PDF）；A4 排版行业调研报告（口径标注、严禁出现求职用途字样）；作战手册 + 模拟面试提示词 + 群面专项 + 跟进话术库
④ 实战复盘录音 → ASR → 逐题拆解（问了什么/答了什么/失分点/修正话术）→ 复盘报告；自动归档简历、刷新总索引；新考题/新失分点/新故事回写档案库

5. 档案 RAG —— 本系统的发动机

面试前：读个人长期档案（主库·含硬约束）+ 面试专用补丁档案
        三要素自检：量化战绩？STAR 故事？软肋清单？缺 → 问用户补齐，绝不硬编
面试后：复盘产出自动回写两个档案库
        新考题 → 总题库 ｜ 新失分点/新故事素材 → 个人档案
        ⇒ 每面一场，档案厚一层，下一场更强

6. 岗位分流器

岗位类型题库侧重武器侧重
销售 / 业务类电销话术、情景实战（客户角色扮演）、阶梯式成交认知业绩数字前置
技术类（运维 / AI 实施）项目 STAR 深问、技术栈匹配、排障思路项目验证数据前置
其他 / 运营类通用行为面 + 岗位认知按 JD 关键词重排简历

分流器只影响 ②③ 的侧重点；①情报采集与④复盘全岗位共用。

7. 工程细节亮点

  • 编号化交付物目录：每家公司一个作战目录（00 执行蓝图 → 15 总览索引），跨场次可检索、可复用
  • 免确认直跑：全流程不问中间确认，只在"正式投递 / 约面试 / 个人信息外发"三个点停下——自动化与风险控制的分界设计
  • 报告口径纪律：行业调研报告严禁出现面试/求职用途字样，可直接当正经行业报告用
  • 防覆盖机制：简历归档带日期戳，总索引脚本自动扫描全部场次生成
