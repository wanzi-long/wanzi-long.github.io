完全离线的 Windows 桌面语音输入挂件：悬浮银河光球 · 中英双语 · 说完 ~0.3s 上屏 · 零网络请求

1. 项目概述

一句话定位：按住热键对电脑说话，一颗银河光球浮现，话音落下，文字已进光标——全程离线，模型全内置。

能力实现
🎙️ 流式语音识别sherpa-onnx 流式 Paraformer（中英双语），说完 ~0.3s 文字上屏
🌌 悬浮银河光球纯 CPU 渲染螺旋星系：随音量加速旋转、星核越说越亮、星点常驻微闪；无背板无边框直接悬浮桌面
🔢 自研轻量 ITN中英数字混搭归一化：三点→3点 · 一万两千八百→12800 · 艾特→@ · 百分之七十→70% · g p t→gpt
📝 自动标点CT-Transformer 标点恢复（int8 量化，~0.01s）
⌨️ 双模式热键开关式 / 长按式，支持 Ctrl+Shift+Space 等组合键自定义
🎨 皮肤 ×4天际蓝 / 星云紫 / 青翠绿 / 落日渐橙，设置页实时预览
🔊 宇宙系音效流星降临 / 星核回响 / 坠入虚空，numpy 程序化合成
🗣️ 个人词库"错词=正确写法"逐行配置，上屏前自动替换
🔒 完全离线本地 CPU 推理，零网络请求，隐私零出机

2. 系统架构

热键监听（hotkey.py，双模式）
   │ 按下 → 播放开始音效 → 光球浮现
   ▼
音频采集 ──▶ sherpa-onnx 流式 Paraformer（中英双语 ASR）
   │              │ 部分结果实时驱动光球（音量→转速/亮度）
   │              ▼
   │        句末判定 → 自研 ITN 数字/符号归一化（itn.py）
   │              ▼
   │        CT-Transformer 标点恢复（int8）
   │              ▼
   │        个人词库替换 → 模拟键入上屏 → 完成音效 → 写入历史(20条)
   ▼
UI 层（app.py · PySide6）：悬浮球 / 托盘菜单 / 设置页 / 4 皮肤
渲染层：numpy 纯 CPU 螺旋星系渲染，沉默时自动降帧省电（v2.6.2）

3. 安装部署 SOP

3.1 安装包方式（推荐分发）

  1. 从 Releases 下载 maruko-voice-setup.exe（NSIS 打包，installer.nsi）
  2. 安装路径可选，默认免管理员权限
  3. 自动创建桌面/开始菜单快捷方式、控制面板卸载入口，可选开机自启

3.2 绿色便携方式

  1. 下载单文件 语音挂件.exe（~365MB，模型内置）
  2. 双击即用，零安装，适合 U 盘携带

3.3 首次启动检查点

  • 托盘出现光球图标即就绪（首次约 5 秒加载模型）
  • 单实例互斥锁生效（v2.6.2）：重复启动不会双开

4. 日常使用 SOP

步骤操作
1 · 定位光标点击任意输入框
2 · 开始按一下 F9（可自定义）→ 银河球浮现，开始说话
3 · 结束再按一下 F9（长按模式：松手即结束）→ 文字自动打进光标
4 · 取消Esc 或点一下光球；拖动光球可移动位置
5 · 纠词识别错的词写入个人词库（错词=正确写法），下次自动修正
6 · 回溯托盘菜单查最近 20 条历史，一键复制

5. 运维与排障 SOP

症状处置
双击无反应检查是否已有实例运行（单实例互斥锁），托盘找图标
首次启动慢正常现象：模型加载约 5 秒，后续热启动
占用偏高确认 v2.6.2+：沉默时星系渲染自动降帧；关闭设置页预览
专有名词识别错进个人词库加映射，无需重训模型
热键冲突设置页改组合键（如 Ctrl+Shift+Space）

6. 版本发布 SOP

  1. 版本号：语义化 vX.Y.Z，变更写入提交信息（示例：v2.6.2 单实例互斥锁防双开 + 沉默降帧省 CPU）
